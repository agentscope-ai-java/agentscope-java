title: 모델 프로바이더

모델 프로바이더 확장은 AgentScope Java를 호스팅형 또는 로컬 채팅 모델 API에 연결합니다. 확장 모듈이 클래스패스에 있으면 `ModelRegistry` id를 통해 각 프로바이더를 선택할 수 있습니다.

- [OpenAI](/v2/ko/integration/model/openai)
- [DeepSeek](/v2/ko/integration/model/deepseek)
- [GLM](/v2/ko/integration/model/glm)
- [Kimi](/v2/ko/integration/model/kimi)
- [MiniMax](/v2/ko/integration/model/minimax)
- [DashScope](/v2/ko/integration/model/dashscope)
- [Gemini](/v2/ko/integration/model/gemini)
- [Anthropic](/v2/ko/integration/model/anthropic)
- [Ollama](/v2/ko/integration/model/ollama)
