---
title: 생태계
---

이 그룹은 메모리나 RAG처럼 특정 카테고리에 속하지 않지만, 런타임, 언어 생태계, 디버깅 도구, 또는 트레이닝 파이프라인을 확장하는 익스텐션을 다룹니다.

| 확장 | 목적 |
| --- | --- |
| [Chat Completions Web](/v2/ko/integration/ecosystem/chat-completions-web) | Agent를 OpenAI Chat Completions 호환 API로 노출 |
| [Studio](/v2/ko/integration/ecosystem/studio) | Agent를 AgentScope Studio에 연결하여 시각적 디버깅 수행 |
| [Training](/v2/ko/integration/ecosystem/training) | 프로덕션 트래픽을 샘플링하여 트레이닝 백엔드로 전달 |
