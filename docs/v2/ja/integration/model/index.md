---
title: モデルプロバイダー
---

モデルプロバイダー拡張機能は、AgentScope Java をホスト型またはローカルのチャットモデル API に接続します。各プロバイダーは、その拡張モジュールがクラスパス上にある場合、`ModelRegistry` の ID を通じて選択できます。

- [OpenAI](/v2/ja/integration/model/openai)
- [DeepSeek](/v2/ja/integration/model/deepseek)
- [GLM](/v2/ja/integration/model/glm)
- [Kimi](/v2/ja/integration/model/kimi)
- [MiniMax](/v2/ja/integration/model/minimax)
- [DashScope](/v2/ja/integration/model/dashscope)
- [Gemini](/v2/ja/integration/model/gemini)
- [Anthropic](/v2/ja/integration/model/anthropic)
- [Ollama](/v2/ja/integration/model/ollama)
