---
title: エコシステム
---

このグループには、メモリや RAG のような特定のカテゴリに属さない拡張機能が含まれます。ランタイム、言語エコシステム、デバッグツール、トレーニングパイプラインを拡張するものです。

| 拡張機能 | 目的 |
| --- | --- |
| [Chat Completions Web](/v2/ja/integration/ecosystem/chat-completions-web) | Agent を OpenAI Chat Completions 互換の API として公開する |
| [Studio](/v2/ja/integration/ecosystem/studio) | Agent を AgentScope Studio に接続し、視覚的なデバッグを可能にする |
| [Training](/v2/ja/integration/ecosystem/training) | 本番トラフィックをサンプリングしてトレーニングバックエンドに供給する |
